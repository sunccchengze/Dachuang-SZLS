## 一、P0 · T9 声场真实化（Web Audio，零外部音频资产）

上一轮交接明确指出 **T9 曾被误报为完成**（仓库里只有 UI 开关、无音频图）。本轮真实现：
三层结构，纯函数模型与引擎分离，可离线断言：

| 文件 | 职责 |
|---|---|
| `twin/src/audio/audioModel.ts` | 纯函数声学帧：涌浪包络（与 WorldTerrain 浪高同源同相位）、拍岸碎浪门、风底噪、风机切风声源挑选与增益、距离/方位衰减。无 DOM 依赖，selftest 直接断言 |
| `twin/src/audio/audioEngine.ts` | Web Audio 图单例：白噪→滤波链（涌浪低通床 / 碎浪带通拍岸 / 风床）+ 每机双声源（切风 AM 哨音 + 传动链音调）+ `PannerNode`（HRTF）3D 定位；主增益受顶栏音量与 M 静音控制 |
| `twin/src/audio/AudioField.tsx` | rAF 驱动：store→engine 每帧同步（相机位姿→listener、 farmFrame→声源增益）， owns `M` 热键与顶栏「声场」开关/音量 |

### 1.1 声学模型口径（与视觉同源，不另造一套浪）
- 涌浪底噪增益 = 浪高包络 `swellEnvAt()`：**与 `WorldTerrain` 顶点位移共用同一组涌浪分量**
  （同频率/同相位/同岸距衰减），海面貌似"浪大声大"在数值上成立而非文案。
- 拍岸碎浪门 = `smoothstep(-340,-60,shore)`（仅近岸带）× `(1−smoothstep(80,600,shore))`
  （**内陆 80–600m 渐隐**：站到场区深处听不到拍岸声；本轮按 QA 实测补的内陆衰减项）。
- 风机切风哨音频率 = 叶pass频 `3×rpm/60`（三叶）对振荡器做 AM 调制；传动链音调 = `rpm/60×97`（齿轮箱一阶）；
  增益 ∝ `uEff`（尾流后机组切风声变"软"）× 距离衰减 `(140/(140+d))^1.25`。
- 3D 定位：每声源 `PannerNode`（HRTF）挂在机舱世界坐标；listener 每帧跟相机位姿与朝向 ——
  镜头掠过机组时哨音从耳侧扫过，方位/距离可听。
- **手势门控**：`AudioContext` 只在用户首次开声（顶栏开关或 `M`）时创建并 resume，符合浏览器
  autoplay 政策；未开声时零音频节点、零 CPU 开销。`window.__aeolus.audio` 为只读 QA 探针
  （state/frame），HUD 不调引擎（单向：AudioField 读 store 推引擎）。

## 二、P1 · T8 草地挂载 + 距离/视锥剔除

### 2.1 瓦片模型（`scene/grassTile.ts`，纯函数、可断言）
- 512m 瓦片网格 ±4550m（324 片）；每片确定性（种子rng）生成**丛**列表：丛=10 株、半径 1.6m；
  目标密度 46,000 株/全域、单瓦片上限 3,600 株（最大余数法分配子格配额）。
- 海洋瓦片 0 株（岸距场门控）；全域陆面 75/324 片非空、共 **45,996 株**。
- 剔除链：`tilesInView`（半径+视锥+岸距排序）→ `drawnFrac` 距离档（<320m 全量 / <760m 50% /
  <1300m 26% / 其余 14%）→ 画质档池：high 24 槽 / medium 14 槽 / low **全关**；
  KEEP_HYST 1.18 防槽位抖动、FADE_TAU 0.7s 淡入淡出。
- 近景密 patch（相机跟随）：700 丛×10 株、R44m、原点 8m 量化（防重 seed 抖动）、
  每帧限 90 丛增量构建、crossfade 0.22s —— 解决"均匀撒=稀疏尖刺"的观感根因。

### 2.2 贴地高度：根因链（不许参数绷带，逐版实测）
| 版本 | 构建耗时/瓦片 | 最大贴地误差 | 结论 |

## 三、P2 · 偏航执行器物理速率与死区

  1.5s 指令滤波、0.5° 读数取整、±30° 量程钳制；HUD 显示「执行器慢转中」徽章与到位 ETA。

- 浏览器实测：`setUnitYaw(0,30)` 后 25s 读 `cmd=30 / actual=7.2° / rate=0.30°/s / slewing=true`。
  证据 `shots/r40_yaw_slew.png`（HUD 滑杆 30°、实际角慢转中）。

## 五·b、R40b 修正（2026-09-17 同日，用户实测反馈驱动）

用户反馈两条：① 声场质量仍有空间；② **"离很远还是有明显声音"＝真 bug**。节点图级根因三条：

| # | 根因 | 修法 |
|---|---|---|
| B1 | 碎浪层**永不静音**：`surfBias/surfLowBias`（0.5/0.45 ConstantSource）硬接 `gain.gain` —— AudioParam 外接输入是**加**在本征值上 → `surfGain=0` 时包络仍 0.5，碎浪嘶声全图常响（"离很远还有声"的主凶） | 删除直流源；直流折进本征值（base×0.5），LFO 深度=同值 → 包络 ∈[0,2base]，surfGain→0 时 base 与摆幅**一起归零** |
| B2 | 切风声 hot ~2.5×：`swishGain` 本征 1 + bladeBias 0.65 = 1.65±depth（包络直流被双计） | 本征值归 0，包络 = 0.65±depth |
| B3 | 距离口径双源：模型曲线 (140/(140+d))^1.25 无地平线（2km 仍 0.033＝安静环境下明显哨音），Panner 又叠第二份 inverse 衰减（与 selftest 曲线对不上） | 曲线收紧为 ^1.6 × (1−smoothstep(1200,2200,d))（**≥2.2km 精确=0**）；Panner `rolloff=0` 只做 HRTF 方位，距离唯一真值回归母函数；gainFloor 0.012→0.004（保住 1km 隐约可闻） |
| B4 | 内陆 3km 仍闻海嗡：陆地门只压 55% | 两段门：0–260m 压 55% + 500–2000m 再渐隐到 15% |

质量项（同轮）：每声部**空气吸收低通**（7kHz@近塔 → ~0.5kHz@1.5km，远声发闷）；风床 gust 呼吸（~14s ±25%）与海床群浪慢摆（~32s ±15%）——床声不再是一条直线嘶声；主链 30Hz 高通 + DynamicsCompressor 兜底（全层热时不削顶、笔记本喇叭不浪费冲程）。
