## 三、T4 实现要点（写在主线基线上，不是照抄 a3）

### ① 波系同源（round38 判定的真缺陷）

旧版 FRAG 的 `waveHeight()` 是 5 条**与几何毫无关系**的等幅正弦（λ≈436/280m，方向/相位各自为政）→
泡沫、浪尖、高光骑在另一套波上。现在：

- `swellN(p)`：公式**逐项镜像** VERT 的 `gerstner()` —— λ 2400/1500、陡度 0.06/0.045、
  时序 0.35/0.50+2.1、相速 `c=√(9.8/k)`、幅 `a=steepness/k`，归一化后 ∈[-1,1]；
- `swellEnv()`：与 VERT 的 `amp` 同式（场心收敛 × 浅水阻尼）—— 几何收的地方着色也收；
- `waveHeight = 0.72·swellN·swellEnv + rippleHeight`：权重和**刻意等于**旧版两条"大尺度涌"
  （0.40+0.32=0.72）→ `crest` 阈值 0.25/0.85 与泡沫统计口径不变，**只换相位来源**；
- `waterNormal` 改为「顶点 Gerstner 几何法线 + 次网格解析梯度×0.5」，不再丢弃几何法线
  （×0.5 与旧式 `normalize(vec3(hL−hR, 2e, hD−hU))` 的斜率口径等价）；
- VERT 的 `gNorm` 同吃 `amp` 包络 —— 修掉「水面几乎不动、法线却大幅摇摆」的自相矛盾。

### ② 真天空反射

旧 `skyRef = mix(暗,亮,uDayF)` 是两个**与视角/太阳方位/月相全无关**的常数。
新增 `seaSky(R, sGate)`：逐项镜像 SkyAurora 的解析层（冰青渐变 / 地平亮带含 R37b 太阳扇区暖化 /
日轮+冷晕+暖晕 / 月盘+内晕+外晕 / 下半球融雾 `uFogColor`），由 `reflect(-V,N)` 驱动。
**不含**照片星野、极光、星点、程序云（云影扫海另议）。权重维持 R36 口径 `0.045+0.07·uDayF`
（新反射色本身更准，不靠提权补色；A/B 口径留在文档里备查）。

### ③ 云掩日月次序

旧版「日轮在云之前（云掩日）、月盘在云之后（不掩月）」自相矛盾。现在统一为
**日 → 月 → 云**：云最后画，可遮日月；夜间云 `×uDay` 不可见，星野/极光/月盘不受影响。

### 自检锁（+7 断言）

- VERT 的 Gerstner 四个数（λ / 陡度 / 时序 / 相位）**解析对表**，且 FRAG `swellN` 必须逐项同值
  —— 以后改波只改一边会被抓；
- `waveHeight/swellEnv/rippleHeight/waterNormal(gN)` 结构锁 + VERT 包络锁；
- `seaSky` 存在且由 `reflect` 驱动 + **旧平涂式必须消失**；
- SkyAurora 源码顺序 日<月<云。
