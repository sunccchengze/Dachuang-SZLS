## 厉今飞 · 数据说明（摘自 `floris(1).zip` 内说明.docx）

- 版本：NREL FLORIS v4.6.6；尾流模型 GCH 与 CC 各生成一套 output。
- 固定参数：NREL 5MW；布局 3 台，间距 378m（3 倍直径），沿 X 轴排列。
- 输入 X（1224 样本）：风速(4–12, 步长0.5)、风向(0–345, 步长15°)、湍流强度[0.06,0.08,0.10]、风机1–3 的 X/Y。
- 输出 Y（1224 样本）：风机1–3 功率、全场总功率。
- 流程：FLORIS 接收风况 → 计算尾流效应与叠加 → 各机入流风速 → NREL 5MW 标准功率曲线 → 输出功率。
- 网络：input 9 维 → output 4 维，全连接。
- 备注：NREL 全套参数偏海上风场，陆上要调整；直接用的仓库 input 文件夹，未额外修改；可视化图片仅为自证风向/尾流影响；每模型 1224 组还没洗，练手时把含零项去除即可；配置 FLORIS 最好用虚拟环境；理论上 CC 精度更高、GCH 更泛用，两套都跑了一遍有差异。

**AI 说明（训练配置）**：训练/验证/测试 = 70/15/15；优化器 Adam；初始学习率 0.001；损失 MSE；隐藏层激活 Swish；输出层 Sigmoid；L2 正则；EarlyStopping；ReduceLROnPlateau；自动恢复验证集最佳；随机种子 42。结构：6 工程特征 → Normalization → Dense(64,Swish) → Dense(128,Swish) → Dense(64,Swish) → Dense(3,Sigmoid) → 三机功率 → 固定求和 → farm_power。
