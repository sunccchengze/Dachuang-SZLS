## 厉今飞的说明（原文整理自厉今飞.docx）

### 数据说明

- **版本**：NREL FLORIS v4.6.6
- **尾流模型**：GCH 和 CC 两种（分别生成一套输出）
- **风机模型**：NREL 5MW
- **布局**：3台，间距378m（3倍直径），沿X轴排列

### 输入变量 X（1224条样本）

| 列名 | 取值范围 |
|------|----------|
| 风速(m/s) | 4~12 m/s，步长0.5（17个值）|
| 风向(°) | 0~345°，步长15°（24个值）|
| 湍流强度 | [0.06, 0.08, 0.10]（3个值）|
| 风机1_X, 风机1_Y, 风机2_X, 风机2_Y, 风机3_X, 风机3_Y | 固定布局 |

计算：17 × 24 × 3 = 1224

### 输出变量 Y（1224条样本）

| 列名 | 单位 |
|------|------|
| 风机1功率 | W |
| 风机2功率 | W |
| 风机3功率 | W |
| 全场总功率 | W |

### FLORIS计算流程

> FLORIS接收风况输入 → 计算尾流效应与叠加 → 得到每台风机入流风速 → NREL 5MW标准功率曲线 → 输出各风机功率

### 关于NREL参数的备注

> NREL全套的参数设计都是为了海上风电场的，如果是陆地的要调整。我这里直接用的GitHub仓库里的input文件夹，没加额外修改。

### 可视化图片的用途

> 可视化图片没啥用，就是为了我自己印证下风向的影响和尾流模型的影响的效果。

### 数据处理提示

> 每个模型下数据1224组，还没洗，要是尝试搭个神经网络练手把含零项去除一下就行了。

### 关于FLORIS配置

> 配置floris最好搞个虚拟环境再运行，怕有冲突。

### 关于两种尾流模型的差异

> 理论上来讲CC（累积-涡旋模型）精度更高，GCH（高斯-涡旋混合模型）更泛用，这俩模型都跑了一遍，有点差异。

### 训练后的模型说明

- **训练集：70%**、验证集：15%、测试集：15%
- **优化器**：Adam，初始学习率0.001
- **损失函数**：MSE
- **隐藏层激活函数**：Swish
- **输出层激活函数**：Sigmoid
- **L2正则化**：1e-5
- **EarlyStopping**：patience=80，监控val_loss
- **ReduceLROnPlateau**：factor=0.5, patience=20, min_lr=1e-6
- **自动恢复**：验证集表现最好的模型
- **随机种子**：42

### 网络结构

```
6个工程特征
  → Normalization
  → Dense(64, Swish)
  → Dense(128, Swish)
  → Dense(64, Swish)
  → Dense(3, Sigmoid)    # 3个风机功率比例
  → 固定求和层          # farm_power = (t1+t2+t3)/3 × 3
  → 输出：[t1_frac, t2_frac, t3_frac, farm_frac]
```

### 输出文件说明

| 文件 | 内容 |
|------|------|
| `wind_farm_power_model.keras` | 训练好的完整模型 |
| `test_metrics.csv` | MAE、RMSE、R²等测试指标 |
| `test_predictions.csv` | 测试集每一行的真实值、预测值和误差 |
| `training_curve.png` | 训练损失曲线（判断过拟合） |
| `true_vs_pred_*.png` | 真实值vs预测值散点图（4张/模型） |

## 当前存在的关键问题（从整理中自然浮现）

### 关于研究目标
- 申请书里写了很宏大的目标（「数据-物理融合驱动」「智能感知与智能调控」「PINN」「启发式优化」），但目前团队的实际工作仅完成了第一步：用FLORIS数据训练了一个回归神经网络。
- 大家心里是否都清楚：这个项目最终要交付什么？是论文？是软件系统？是控制算法？还是三者都有？

### 关于数据
- FLORIS产生的数据「太干净」了——神经网络几乎可以完美拟合（R²>0.998）。这可能说明FLORIS模型本身过于光滑，缺乏真实湍流的复杂性。
- 数据规模（1224条）对于神经网络来说偏小，而且八成以上的参数都集中在网络的后半部分。
- 风向步长15°、湍流强度仅3个离散值，这些采样密度是否足以支撑后续的控制应用？

### 关于物理融合
- 目前唯一的物理约束是输出层的求和关系（farm_power = Σ turbine_power）。
- 申请书里提到的PINN路线尚未起步。Navier-Stokes方程、质量守恒、尾流守恒等物理规律如何嵌入到神经网络中，目前还没有技术方案。

### 关于组间协作
- AI组（厉今飞）训练的模型输出是3个风机功率，但可视化系统（孙承泽）和优化系统（洪祖名）目前是基于2台风机的插值模型。
- 仿真组（田）生成的流场数据（fields/*.npz）和AI组的FLORIS批量数据之间是否存在重复或一致性问题尚不清楚。
