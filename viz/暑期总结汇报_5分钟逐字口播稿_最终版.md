## 0分20秒至0分55秒

[展示早期 Streamlit 截图和现在的首页]

最早的 Streamlit 版本基本是我自己搭的。当时我从 GitHub 找到 FLORIS，配置两机基础工况，批量扫描偏航角，导出功率和水平流场，再用 Streamlit 做滑块、热力图和功率曲线。那一版现在看起来比较复古，但数据读取、交互控件和多页面结构都是从那时开始搭的。

后来我开始大量使用 AI Agent，把它逐步改成现在的静态网站。代码和数据都放在我的公开 GitHub 仓库里。当前版本在单独的开发分支，还没有合并到 main。会后我把分支链接发到群里。

## 0分55秒至1分35秒

[移动首页鼠标，再进入尾流页]

现在的网站把我的 FLORIS 基础数据和你们提供的流场、POD、优化、功率跟踪结果接到了一起。我负责数据接入、页面结构、交互和视觉呈现。

首页右侧是鼠标跟随的三乘三数字风洞，风机角度、流线和空间视差会随鼠标变化。尾流页把偏航滑块和三张图连在一起，拖动以后，速度场和功率图同步更新。开会时操作一次，就能把前后变化放在一起看。

## 1分35秒至2分15秒

[进入阵列页，再进入3D风场]

阵列页里的30度、20度和0度策略，以及功率跟踪评测，都是你们提供的。我负责把数据做成策略切换、九台单机功率表、流场对照和图表联动。网页的代理表搜索和 PPO 离线结果也分开说明，避免混淆。

3D 风场这部分，我主要学习了 Three.js 的场景、相机、风机模型和交互控制，用来帮助理解空间位置和策略变化。数值流场与结构示意在页面里分别标清楚了。

## 2分15秒至3分00秒

[回到首页或展示设计前后对比]

网页风格上，我在 Awesome Design MD 里看了 Vercel 的设计分析，也学习了 UI UX Pro Max 和其他高 Star 设计 Skill。我喜欢 Vercel 简约、细致又有丰富动效的感觉，和风电科研内容比较合适。我自己比较在意页面不能太空，也不能堆满卡片，所以后来用动态流线和连续数据区补充信息。

我保留了发丝线、网格、玻璃和鼠标动效，把配色调整成浅色白绿和水青，同时保证图表的信息量。现在我主要在 Arena 上使用 AI Agent。它帮我拉取和阅读开源仓库、写代码、调网页和排查错误，我负责定目标、选方案，再检查结果。

## 3分00秒至3分55秒

[展示 GitHub Skill、Jupyter Notebook 和 Nature 风格图]

科研绘图这块，我在 GitHub 上学习了 Nature Figure 一类的开源 Skill，也看了其他高 Star 项目的代码结构。我把数据检查、样式、面板编号和导出函数拆开，方便重复使用。

早期 Streamlit 里的图基本是我自己做的。后来我又用 Jupyter Notebook 和 Python 练习数据清洗、选图、配色、子图排版和批量导出，用到 Pandas、NumPy、Matplotlib 和 Seaborn。仓库里的功率曲线、热力图、POD 模态和三维曲面，大部分由我运行和调整；也有一些是 AI 推荐或执行，我再检查数据、单位和图形。

输出时我参考 Nature 常见尺寸，保留300 DPI的PNG、矢量PDF和部分SVG，并把图缩到最终尺寸再检查。

PS 我接触了大概一周，学了画布设置、图层分组、文字和形状、蒙版、智能对象、调色和抠图。目前没有专门做完整 PSD，因为暂时没有直接需求。后面真正需要时再继续练。

## 4分15秒至4分50秒

[展示以前的挑战杯或腾飞杯答辩PPT]

PPT 是我基础比较扎实的一块。之前做挑战杯、腾飞杯的 PEEK 聚醚醚酮成形项目时，答辩 PPT 基本由我独立制作，再根据博士生和各轮指导意见反复修改。我能把信息排得密一些，但不显得乱，科研图和数据表也能保持清楚，配色尽量不刺眼。

现在 AI 做 PPT 的审美还不能替代人工。AI 可以整理材料、提供初稿，最后的版式、节奏和视觉效果还是由我自己调整。
