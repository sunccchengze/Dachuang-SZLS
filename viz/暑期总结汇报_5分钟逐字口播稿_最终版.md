# 暑期总结汇报五分钟逐字口播稿

> 建议按平时组内讨论的语速讲。方括号里是页面切换提示，不需要念出来。

## 0分00秒至0分15秒

我直接讲一下暑假这段时间可视化部分的进展。前面三分钟看网页，后面讲科研绘图、开源 Skill、PS 和 PPT。

## 0分15秒至0分55秒

[停在首页]

网页这部分，我把大家的结果接进了同一个静态网站。里面有田铭雨的流场数据和袁夫达的 POD 结果，基线工况由厉今飞整理，优化和功率跟踪数据来自洪祖名。目前有十五个现役页面，都可以从顶部导航直接进入。

我主要负责数据格式、网页结构、交互和整体视觉。CSV、JSON 和 NPZ 会提前转成网页能读取的数据，打开以后就在浏览器本地运行，断网也可以演示。

## 0分55秒至1分35秒

[移动首页鼠标，再进入尾流页]

首页右侧的三乘三数字风洞是我做的结构示意。鼠标移动以后，风机角度、流线和空间视差会一起变化。这里我把“结构示意”和“数值流场”分开写清楚，避免让人误以为这个动画就是 CFD 结果。

尾流页用的是已经算好的工况数据。我做了偏航滑块和三张图之间的联动，速度场、总功率和两台风机的功率分解会同步更新。这样开会时拖一次滑块，就能把前后变化放在一起看，不用来回翻静态截图。

## 1分35秒至2分20秒

[进入阵列页、POD页和功率跟踪页]

阵列页里的30度、20度和0度策略是洪祖名搜索得到的。我做的是策略切换、九台单机功率表、流场对照和图表布局。功率跟踪页里的0.523%稳态误差和测试结果也来自洪祖名。我把网页的代理表反向搜索和他的 PPO 离线评测分成两个区域，免得大家看页面时把两种方法混到一起。

POD 页使用袁夫达提供的结果。我把能量占比、空间模态和系数变化重新组织到同一页，重点处理图的顺序、尺寸和说明文字。算法结果归他们，我负责把这些内容接进网站，做得清楚、顺手，也方便后面汇报。

## 2分20秒至3分00秒

网页做到后面，我开始更注意一致性和可复现。十五页的导航、标题、配色、图例位置和移动端布局都统一了一遍，Plotly、Three.js 和字体也改成了本地文件。

我还给首页数字风洞和尾流交互写了自动运行检查，同时检查链接、数据接口和静态资源。现在网页可以稳定地本地运行和部署。对我来说，这一部分练到的东西主要是前端开发、交互设计，以及怎么把不同组员的数据接到同一套可视化系统里。

## 3分00秒至4分00秒

[展示 GitHub Skill、Jupyter Notebook 和 Nature 风格图]

科研绘图这块，我在 GitHub 上找了一些 Star 数比较高的开源绘图 Skill，重点看它们的代码结构。我学着把数据检查、期刊样式和导出函数拆开，后面换数据时就不用从头改整张图。

实际画图主要在 Jupyter Notebook 和 Python 脚本里完成。我用 Pandas、NumPy、Matplotlib 和 Seaborn，画了功率曲线、热力图、POD 模态、箱线散点和三维曲面。数据来自大家，我负责选图、排版和导出。

这部分也用了 AI 辅助编程。AI 帮我读 Skill、搭第一版代码、查 API 和改报错，我再核对字段、单位、坐标轴和最终图形。输出参考 Nature 常见的单栏和双栏尺寸，保留300 DPI的PNG、矢量PDF和部分SVG。现在我会把图缩到最终尺寸再检查，不只看电脑上放大的效果。

## 4分00秒至4分25秒

[展示 PSD 图层截图]

PS 方面我学了画布和分辨率设置、图层分组、文字标注、矢量图形和智能对象。现在可以把文字、标注、风机图元、流场底图和背景分层整理，也尝试用 Python 辅助生成300 DPI的 PSD。目前可以比较稳定地输出文件，不过复杂蒙版、精细抠图和印刷色彩还要继续练。

## 4分25秒至4分50秒

[展示答辩PPT页面]

PPT 是我原来基础比较扎实的一块。这个暑假我又整理了答辩 PPT 相关的 Skill，包括页面网格、信息层级、图表排版和口播节奏。我现在可以把网页截图、科研图和数据表重新组织成一套比较完整的答辩 PPT，也能根据五分钟、十分钟这些不同时长调整内容密度。

## 4分50秒至5分00秒

这段时间我把数据接入、网页、科研图、PSD 和 PPT 这条可视化流程都实际做了一遍。我的部分就这些，大家直接提问题。
