# 暑期总结汇报五分钟逐字口播稿

> 建议按平时讨论的语速讲。方括号里是页面切换提示，不需要念出来。

## 0分00秒至0分15秒

我直接讲一下暑假这段时间我在可视化方面做的事情。前面三分钟讲网页，后面讲 Jupyter Notebook、Python 科研绘图和 PS 的学习情况。

## 0分15秒至0分55秒

[停在首页]

网页这部分，我主要做的是把组员提供的仿真数据、降阶结果和控制结果接到同一个静态网站里。目前网站有十五个现役页面，尾流、阵列、POD、功率跟踪和三维流场都可以直接从顶部导航进入。

我把原来分散的 CSV、JSON、NPZ 和图片整理成网页能够读取的格式，也统一了每个页面的数据接口。网站没有后端，打开以后，滑块、图表和三维场景都在浏览器本地运行，断网也可以演示。

## 0分55秒至1分40秒

[移动首页鼠标，再进入尾流页]

交互和视觉呈现是我投入比较多的部分。首页的三乘三数字风洞支持鼠标跟随，鼠标位置会影响风机角度、流线和空间视差。这里明确写成结构运行示意，没有把动画说成真实 CFD 流场。

尾流页使用的是组员已经算好的工况数据。我做了滑块和图表之间的联动，拖动偏航角以后，速度场、总功率和两台风机的功率分解会一起更新。这样在讨论时，不需要来回翻几张静态图片，一次操作就能把变化过程对照起来。

## 1分40秒至2分20秒

[进入阵列页和功率跟踪页]

这里我把分工说清楚。阵列页里的30度、20度和0度推荐策略，是负责优化的组员计算和搜索得到的。PPO 页面里的稳态误差、调节时间和测试回合，也来自负责强化学习的组员。我没有训练这些模型，也没有把这些算法结果算成自己的成果。

我做的工作，是把他们交付的结果整理成统一的数据格式，再完成策略切换、九台单机功率表、图表联动和页面说明。功率跟踪页里，我也把网页上的代理表反向搜索和组员提供的 PPO 离线评测分开写，避免看页面的人误以为浏览器正在运行 PPO。

## 2分20秒至3分00秒

网页做到后面，我开始更注意数据来源和表达边界。页面上的数字需要能回到对应的 CSV、JSON 或图源，三维结构示意也要和数值速度场区分开。我把 Plotly、Three.js 和字体都改成本地文件，统一了十五页的导航、字体、配色和移动端布局。

最后我为首页数字风洞和尾流交互各做了一套自动检查，又加了资源、链接和数据契约检查。现在网站可以比较稳定地本地运行和部署。网页部分基本就是这些。

## 3分00秒至4分00秒

[切到 Nature 风格图汇总页或 Jupyter Notebook 截图]

网页之外，我用 Jupyter Notebook 把 Python 科研绘图的流程跑了几遍。数据仍然来自组员的仿真和算法结果，我负责检查字段、数组形状和单位，再用 Pandas、NumPy、Matplotlib 和 Seaborn 组织成图。

这段时间我主要练习怎么根据数据选图。两机功率可以用折线和增益曲线，多风速工况适合用热力图，POD 数据需要同时看能量占比和空间模态。样本数量比较少时，我会用箱线图加散点，把原始点保留下来，不只给一个均值。

我参考了 Nature 常见的单栏和双栏尺寸，调整字号、线宽、图例和面板编号。连续数据主要用 viridis，正负变化用 RdBu。导出时保留300 DPI的PNG和矢量PDF，部分图也输出SVG。我以前更关注图有没有画出来，现在会再缩到最终尺寸看一遍，很多图在这一步还要重新调。

## 4分00秒至4分40秒

[展示 PSD 图层截图]

PS 方面我从基础操作开始学，练习了画布尺寸、分辨率、图层分组、文字标注、矢量图形和智能对象。现在可以按比较固定的结构整理 PSD，把文字、标注、风机图元、流场底图和背景分开，后面修改会方便一些。

我也试着用 Python 辅助生成300 DPI的分层 PSD，目前已经能比较稳定地输出文件。我的 PS 还在基础阶段，复杂蒙版、精细抠图和印刷色彩管理都需要继续练。

## 4分40秒至5分00秒

这个暑假我自己的收获，主要是把数据接入、网页交互、Python 出图和 PSD 分层这些可视化工作实际做了一遍。算法结果来自对应的组员，我负责把它们准确、清楚地呈现出来。

我这部分就讲这些，大家直接提问题。
