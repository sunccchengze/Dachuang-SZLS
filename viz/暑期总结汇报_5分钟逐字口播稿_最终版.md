## 0分15秒至1分00秒

[展示早期 Streamlit 截图和现在的首页]

最早的 Streamlit 版本基本是我自己搭的。FLORIS 是我从 GitHub 找到的，下载和整理时也用了 AI。环境装好以后，我配置两机基础工况，批量扫描偏航角，导出功率和水平流场，再用 Streamlit 做滑块、热力图和功率曲线。那一版现在看起来比较复古。数据读取、交互控件和多页面结构都是从那时开始搭的。

后来我大量使用 AI Agent，把它改成现在的静态网站。代码和数据都放在我的公开 GitHub 仓库里。当前版本在尚未合并 main 的开发分支，已经部署完成。我等下把分支链接发到群里。

## 1分00秒至1分40秒

[移动首页鼠标，再进入尾流页]

现在的网站把我的 FLORIS 基础数据和你们提供的流场、POD、优化、功率跟踪结果接到了一起。数据格式主要由 AI 帮我整理，我来决定每个页面展示什么、怎么操作，以及最后采用什么视觉效果。

首页右侧是鼠标跟随的三乘三数字风洞，风机角度、流线和空间视差会随鼠标变化。尾流页把偏航滑块和三张图连在一起，拖动以后，速度场和功率图同步更新。我现在拖一次滑块，前后变化就能放在一起看。

## 1分40秒至2分35秒

[进入阵列页，再进入3D风场]

阵列页里的30度、20度和0度策略，以及功率跟踪评测，都是你们提供的。我借助 AI 把这些数据做成策略切换、九台单机功率表、流场对照和图表联动。网页的代理表搜索和 PPO 离线结果各自标了来源，页面上看起来会更清楚。

3D 风场这部分，我主要学习了 Three.js 的场景、相机、风机模型和交互控制。数值流场与结构示意在页面里分别标清楚了。

做这些页面时，我也补了一些项目基础，包括 POD 降阶、偏航产生的对转涡对、尾流包络、余弦功率损失和尾流恢复。我比你们低一个年级，基础上确实有差距。现在还谈不上深入，但至少知道图和参数在表达什么，做页面时不容易把概念写错。

## 2分35秒至3分10秒

[回到首页或展示设计前后对比]

网页设计阶段，我在 GitHub 搜集了 Awesome Design MD、UI UX Pro Max 等 Skill，安装给 AI Agent 使用。Agent 参考其中的 Vercel 设计分析帮我改页面。我个人喜欢它简约、细致又有丰富动效的感觉，所以保留了发丝线、网格、玻璃和鼠标动效，配色换成浅色白绿和水青。

## 3分10秒至3分55秒

[展示 GitHub Skill、Jupyter Notebook 和 Nature 风格图]

科研绘图阶段，我在 GitHub 搜集了 Nature Figure 一类的开源 Skill，也找了其他高 Star 科研绘图项目，然后安装给 AI Agent。Skill 是给 Agent 读取的，用来约束数据检查、样式设置和导出流程。

我自己学习的是 Jupyter Notebook 和 Python 绘图。早期 Streamlit 里的图基本是我做的，后来又练习了数据清洗、选图、配色、子图排版和批量导出，用到 Pandas、NumPy、Matplotlib 和 Seaborn。仓库里的功率曲线、热力图、POD 模态和三维曲面，大部分由我运行和调整；也有一些是 AI 推荐或执行，我再检查数据、单位和图形。

输出时我参考 Nature 常见尺寸，保留300 DPI的PNG、矢量PDF和部分SVG，并把图缩到最终尺寸再检查。
