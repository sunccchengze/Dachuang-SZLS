# 暑期总结汇报五分钟逐字口播稿

> 建议按平时说话的速度讲。方括号里是页面切换提示，不需要念出来。

## 0分00秒至0分20秒

我直接汇报一下暑假这段时间可视化部分做了什么。前面大概三分钟讲网页，后面讲我用 Jupyter Notebook 和 Python 画图，以及学习 PS 的情况。

## 0分20秒至0分55秒

[停在首页]

网页这部分，我把组里已有的仿真数据、POD 结果和功率跟踪结果整理到一个静态网站里。目前有十五个现役页面，尾流、阵列、降阶、功率跟踪和三维流场都可以从顶部导航直接进入。

网站没有后端。数据提前整理成 CSV、JSON 和前端数据文件，打开页面以后，滑块和图表在浏览器本地运行。关键交互的响应时间小于零点五毫秒，断网也可以演示。

## 0分55秒至1分40秒

[移动首页鼠标，然后进入尾流页]

首页右侧是我做的三乘三数字风洞示意。鼠标移动时，第一排风机会跟着改变偏航角，流线、尾流和空间视差也会变化。这部分主要用于帮助理解阵列结构，没有把示意动画当成真实 CFD 结果。

尾流页里，我把速度场和功率变化放在同一个操作里。在八米每秒、前后间距为五倍叶轮直径的工况下，两台风机都是零度时，总功率是2190千瓦。把上游风机转到正25度以后，上游功率会下降，下游从436千瓦回升到909千瓦，总功率增加到2368千瓦，增益是8.13%。拖动一次滑块，就能看到尾流让开下游风机的过程。

## 1分40秒至2分30秒

[进入阵列页，切换四种策略]

三乘三阵列页比较了四种偏航策略。九台风机全部保持零度时，总功率是8095千瓦。只调整第一排到30度，功率提高到9299千瓦。前两排都转30度时，功率达到9935千瓦。逐排搜索得到的组合是30度、20度和0度，总功率是10041千瓦，比基准工况提高24.04%。

我在做这个页面时，对第二排为什么取20度理解得更清楚了。第二排继续转30度，会增加自身的功率损失。转20度已经能给第三排留出风道，同时可以多保留一些自身功率。网页把九台单机功率和流场放在一起，这个取舍比较容易看出来。

## 2分30秒至3分00秒

[快速切到POD页和功率跟踪页]

POD 页面里，前两个模态覆盖97.97%的能量。我把模态能量、空间分布和系数变化放在一起，方便理解降阶以后保留了哪些流动特征。

功率跟踪页面使用了两百个固定测试回合的评测结果，平均稳态误差是0.523%，平均调节时间是0.944秒。网页上的实时反向搜索和PPO离线评测分别说明，没有把两种方法混在一起。

## 3分00秒至4分00秒

[切到Nature风格图汇总页或Jupyter Notebook截图]

网页之外，我还用 Jupyter Notebook 把科研绘图的流程完整跑了几遍。数据主要来自 CSV、JSON 和 NPZ 文件，我先检查字段、数组形状和单位，再用 Pandas、NumPy、Matplotlib 和 Seaborn 出图。

我练得比较多的是图的选择。两机功率用折线和增益曲线，多风速工况用热力图，POD 把能量占比和空间模态放在一起。样本比较少时，我改用箱线图加散点，保留原始数据，不只画一个均值柱。

我参考了 Nature 常见的单栏和双栏尺寸，统一字号、线宽、图例和面板编号。连续数据主要用 viridis，正负变化用 RdBu。输出时同时保留300 DPI的PNG和矢量PDF，部分图也导出了SVG。Python 能把图画出来只完成了一半，缩到论文尺寸以后是否还能看清，往往更费时间。这点我以前没有太注意。

## 4分00秒至4分40秒

[展示PSD图层截图]

PS 方面我从基础操作开始学，主要练习了画布尺寸和分辨率设置、图层分组、文字标注、矢量图形和智能对象这些内容。现在可以按比较固定的结构整理 PSD，把文字、标注、风机图元、流场底图和背景分开，后面修改其中一层会方便很多。

我也尝试用 Python 辅助生成300 DPI的分层 PSD，已经能比较稳定地输出文件。目前掌握的还是基础流程，复杂的蒙版处理、精细抠图和印刷色彩管理还需要继续练习。

这个暑假，我把网页、Python 绘图和 PSD 分层流程都实际走了一遍。很多地方还在学，但现在已经能把一组数据整理成可以展示、也方便继续修改的成果。
